## 1. Color Palette

Pure black/white/red. No other colors except artwork content.

| Token | Value | Usage |
|-------|-------|-------|
| `--gn-black` | `#000000` | Primary background — pure OLED black |
| `--gn-black-soft` | `#0A0A0A` | Card surfaces, slight elevation |
| `--gn-black-mid` | `#141414` | Hover states, subtle elevation |
| `--gn-white` | `#FFFFFF` | Primary text |
| `--gn-white-muted` | `rgba(255,255,255,0.6)` | Secondary text, captions |
| `--gn-white-dim` | `rgba(255,255,255,0.3)` | Tertiary text, disabled |
| `--gn-red` | `#CC0000` | Accent — gradients, highlights, active states |
| `--gn-red-glow` | `rgba(204,0,0,0.4)` | Hover glow on thumbnails |
| `--gn-overlay` | `rgba(0,0,0,0.7)` | Navigation overlay on project detail |

### Gradient
```css
--gn-gradient-hero: linear-gradient(180deg, #000000 0%, #CC0000 100%);
--gn-gradient-subtle: linear-gradient(180deg, transparent 0%, rgba(204,0,0,0.15) 100%);
```

## 3. Layout

### Global
- **No max-width container** — full-bleed pages
- **No visible borders** — separation by negative space and color contrast
- **No border-radius** — 0px everywhere (ZGNAL genome preserved)
- **No box-shadows** — pure flat, depth via layering

### Grid Systems

**Homepage**: No grid — absolute/relative positioning for orbit
**Archive**: CSS Grid — `repeat(3, 1fr)` with `gap: 2px`
**Project Detail**: Full viewport, no grid
**Info**: Two-column — `grid-template-columns: 1fr 1fr` with `gap: 64px`

## 6. Art Zones

All artwork is rendered by `ZEngine.render()` from `z-engine.js`.

| Page | Zone | Rendering |
|------|------|-----------|
| Homepage orbit | 28 thumbnails (70x70) | Low-res SVG, all 7 archetypes represented |
| Archive grid | 31 cards (square, ~400x400) | Medium-res SVG, lazy loaded via IntersectionObserver |
| Project detail | Full viewport | High-res SVG, 100vw centered, paper texture enabled |

**Rendering call**:
```js
ZEngine.render(targetElement, {
  archetype: work.archetype,
  palette: work.palette,
  seed: work.seed,
  density: work.density
});
```

## 8. Immersive Motion (3 patterns — within budget)

### 1. Orbit Rotation (Homepage)
```css
@keyframes orbit-rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
.orbit-ring {
  animation: orbit-rotate 120s linear infinite;
}
.orbit-thumb {
  animation: orbit-counter-rotate 120s linear infinite;
}
@keyframes orbit-counter-rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(-360deg); }
}

@media (prefers-reduced-motion: reduce) {
  .orbit-ring, .orbit-thumb { animation: none; }
}
```

### 2. Marquee Scroll (Homepage)
```css
@keyframes marquee {
  from { transform: translateX(0); }
  to { transform: translateX(-50%); }
}
.marquee-inner {
  animation: marquee 40s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  .marquee-inner { animation: none; overflow-x: auto; }
}
```

### 3. Archive Card Reveal (Archive)
```css
.archive-card .title-overlay {
  transform: translateY(100%);
  transition: transform 300ms cubic-bezier(0.32, 0.72, 0, 1);
}
.archive-card:hover .title-overlay {
  transform: translateY(0);
}

@media (prefers-reduced-motion: reduce) {
  .archive-card .title-overlay {
    transform: translateY(0);
    opacity: 1;
  }
}
```
